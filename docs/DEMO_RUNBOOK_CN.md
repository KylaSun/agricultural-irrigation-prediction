# 5–8 分钟演示流程

## 0:00–0:45｜问题与边界

说明 RLLS 研究的是在低成本、有限传感器条件下预测能力与稳定性的变化。强调页面当前使用 MockModel，不展示虚构准确率，也不控制灌溉。

## 0:45–1:45｜完整链路

展示 ESP32 每秒输出一条 JSONL，Python 独立采集并写 CSV，Streamlit 只读 CSV。指出 `null ≠ 0`、UTC 时间和每类传感器状态。

## 1:45–3:00｜实时/模拟读数

先用模拟数据展示四支 SEN0308 的读数和趋势，再切换一份回放 CSV。展示 ESP32 状态、最后更新时间和质量状态。

## 3:00–4:30｜C1/C2/C3 配置对比

依次选择 C1 Soil-only、C2 Low-cost hybrid、C3 Sensor-rich，再说明 Weather-only 是额外基线。切换单探头与“四探头综合值”，说明综合值使用至少两支有效探头的中位数，但模型仍只接收一个 `soil_moisture`。关闭探头，确认综合参与数量随之变化；有效探头少于两支时应为 missing。C3 应明确显示 EC、pH 和过去4小时用水量缺失。

## 4:30–5:30｜异常与诚实性

回放 `simulated_missing.csv`、`simulated_out_of_range.csv`、`simulated_stale.csv`，说明无法读取、关闭、超范围和过旧是不同状态，不能都写成 0。

## 5:30–6:30｜与研究模型的关系

说明现有仓库已有时间切分、基线与 sensor ablation，但研究中的 `future_dry` 与历史次日灌溉事件含义不同；Demo 适配器等待正式模型契约。

## 6:30–8:00｜下一步

展示模型交接清单、接线与校准记录。下一阶段先锁定硬件型号/校准，再导出三个可复现 pipeline，最后做现场连续采集与漂移验证。
