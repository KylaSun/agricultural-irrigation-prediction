# 模型负责人交接清单

在接入真实模型前逐项填写并由模型负责人确认：

- [ ] 模型文件、SHA256、来源与格式（joblib/pickle/其他）
- [ ] Python、scikit-learn、pandas、numpy、joblib 等精确版本
- [ ] 任务：分类还是回归；训练 target 的严格定义与时间窗口
- [ ] 精确特征名称、顺序、数据类型、单位、数据来源和时间对齐方式
- [ ] 完整预处理：聚合、rolling window、缩放、编码、校准、截断
- [ ] 缺失值策略，以及策略在哪个 split 上 fit
- [ ] 类别编码和正类含义
- [ ] 输出类别/数值含义，是否有概率校准
- [ ] 决策阈值及其选择依据
- [ ] 三种模式是否对应三个独立模型/三个 pipeline
- [ ] 一条固定测试输入及期望 `predict()`/`predict_proba()` 输出（允许容差）
- [ ] 训练时间范围、地理范围、适用边界与已知漂移
- [ ] 模型是否允许线上缺失字段；若允许，如何处理
- [ ] 安全声明：结果是否仅用于研究展示，不触发执行器

特别需要澄清：仓库中 `irrigation_next_day` 与 `future_dry` 不是同一个任务；不得只写“灌溉预测”而省略目标定义。
